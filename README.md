
# 💰 Personal Expense Tracker

A Python-based command-line application to track personal income and expenses, built using Object-Oriented Programming, file handling, and exception handling.

## 🎯 Project Overview
This project was built as part of the DigiSkills "AI with Python" course to apply core Python concepts in a real-world use case.

## 🛠️ Features
- Add and categorize expenses
- Track income vs spending
- Save and load data using file handling
- Custom exception handling for invalid inputs
- Built with clean OOP principles (classes, encapsulation, `__init__`, `self`)

## 🧰 Concepts Used
- Object-Oriented Programming (Classes, Objects, Encapsulation)
- File Handling (read/write/append)
- Exception Handling (try/except/else/finally, custom errors)

## 🚀 How to Run
1. Clone this repository
2. Open `Personal_Expense_Tracker.ipynb` in Jupyter Notebook
3. Run all cells to start the tracker
